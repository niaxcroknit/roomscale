룸 스케일 개인정보처리방침

시행일: 2026년 10월 26일

1. 수집하는 개인정보

룸 스케일(이하 "앱")는 개인정보를 수집하지 않아요. 회원가입, 로그인, 광고, 분석 도구가 없고, 앱이 인터넷으로 정보를 보내지 않아요.

2. 앱 안에 저장되는 정보

사용자가 입력한 방 크기, 가구 이름과 치수, 배치안, 수납함 정보는 사용자의 기기 안에만 저장돼요. 개발자를 포함해 누구도 이 정보를 볼 수 없어요. 앱을 지우면 함께 지워져요.

3. 백업 파일

"백업 파일 저장"을 누르면 배치 정보가 담긴 파일을 만들고, 사용자가 고른 곳(예: 구글 드라이브, 메신저, 내 파일)으로 보내요. 어디로 보낼지는 사용자가 직접 정하며, 앱은 그 파일을 따로 보관하거나 전송하지 않아요.

4. 권한

앱은 카메라, 위치, 연락처 같은 권한을 요청하지 않아요. 백업 파일을 불러올 때는 사용자가 직접 고른 파일만 읽어요.

5. 아동의 개인정보

앱은 어떤 개인정보도 수집하지 않으므로 아동의 개인정보도 수집하지 않아요.
